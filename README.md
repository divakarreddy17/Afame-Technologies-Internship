### 🔍 Problem Statement
The goal of this project is to build a machine learning model that predicts whether a loan application will be approved or rejected based on applicant details.

### 🎯 Objectives

- Conduct exploratory data analysis (EDA)  
- Build classification models  
- Evaluate model performance  

### 🧠 Methodology

**Data Processing**
- Handled missing values  
- Encoded categorical variables  
- Performed feature selection  
- Train-test split  

**Models Used**
- Logistic Regression  
- Decision Tree / Random Forest *(update if different)*  

**Evaluation Metrics**
- Accuracy  
- Confusion Matrix  
- Precision & Recall  

### 📊 Key Insights

- Identified key factors influencing loan approval  
- Built a predictive classification model  
- Evaluated model performance on unseen data
